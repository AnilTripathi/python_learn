# Python Learning Programs

This repository contains a collection of basic Python programs for learning purposes.

## Programs

- **average_calculator.py**: Calculates the average of numbers.
- **celsius_to_fahrenheit.py**: Converts temperature from Celsius to Fahrenheit.
- **circle_area.py**: Calculates the area of a circle.
- **decimal_split.py**: Splits a decimal number into integer and fractional parts.
- **FirstProgram.py**: A simple first program.
- **operator_precedence.py**: Demonstrates operator precedence in Python.
- **simple_interest.py**: Calculates simple interest.
- **swap_two_number.py**: Swaps two numbers.
- **two_numbers_operations.py**: Performs operations on two numbers.
- **type_conversion.py**: Demonstrates type conversion in Python.
- **user_input.py**: Takes user input.

## How to Run

Run each program using Python:

```bash
python program_name.py
```

Replace `program_name.py` with the actual file name.
